# LIO/LIVO環境依存性比較：8条件の凍結仕様 v1

確定日：2026-11-08。ユーザー合意に基づく今回の主比較の仕様。
目的は環境に対する挙動と画像の寄与の説明であり、推定精度の改善・パラメータ探索は行わない。
**出発と帰着の比較は評価しない。** 過去資料の帰着指標は今回の成績に取り込まない。

## 主比較の定義

| family | ソース／バイナリ | 推定構成 |
|---|---|---|
| `f281` | f281e70当時の推定器＋既存offline reader、SHA256 `5a045a53…` | 当時のYAML、KNN対応・従来IEKF、X-ICP／時間窓なし |
| `temporal2` | 保存済み現行バイナリ、SHA256 `a618fa6a…` | 採用YAML `go2w_mid360_online.yaml`、2秒・最大6状態・legacy_voxel初期化、X-ICP OFF |

各family内はLIO／LIVOの `common.img_en` のみを変える。両bagで同じfamilyの設定を使う。
設定は [configs](configs) の4ファイル、完全なハッシュと実行記録の対応は [manifest.json](manifest.json) に固定した。
旧版の設定には当時のoffline制御も含む。設定ファイルは直接実行用コマンドではない。
新規再生時のrate・duration・出力先・診断は実験制御として別ファイルへ派生し、全差分を保存する。
新規再生に旧設定の `offline.rate: 0` を流用しない。

現行デフォルトIEKF＋X-ICP、6秒時間窓、相対面修正直前、0.2秒周期の旧LIVO実験は主比較の対象外。
それらのcaptureを8条件の欠測補完に使わない。
時間窓ON時はX-ICPが処理経路上で無効になる。

診断設定の違いを自動的に無影響とは認定しない。

## 評価対象と対象外

評価するもの：

- 同じbag・同じ時刻の軌道位置／姿勢差、速度・高さの変化、静止区間の揺れ。
- 非有限状態・速度超過・更新停止などの発生時刻と、観測された処理区間。
- IMU bias、共分散、LiDAR／視覚の更新量、残差、対応の質と方向。
- 上記の変化と同期した原画像・点群・環境区分。

評価しないもの：出発帰着の点群NN、重なり率、帰着壁差、閉路誤差、終点と原点の距離、再訪地図の照合による成績。
帰着を基準にした区間選択・採否・打ち切りもしない。
保存軌道と地図は逐次推定出力を保持し、ループ閉じ・事後軌道補正を加えない。
独立真値がないため軌道差をATEや真の位置誤差と呼ばない。

## 時刻・座標・区間の統一

1. 各CSVの時間原点をコード・bag timestampと照合し、同一bagの先頭LiDARを共通の0秒とする。
2. 軌道比較は0.1秒格子で位置を線形補間、姿勢をSLERPする。欠測・停止後を補間／外挿しない。
3. 生の座標での差を保存する。比較用には共通t=20秒の位置・yawだけを合わせ、roll/pitchとスケールを保持する。必要状態がなければ欠測扱いとし、差を小さくするために基準時刻を動かさない。
4. 20秒以前は初期化の診断区間として扱う。20秒は座標比較の基準で、環境分類や真値を意味しない。全軌道の最小二乗整列は行わない。
5. 4条件共通の有効区間を主な横断比較に使い、各LIO/LIVO対の共通区間も併記する。長く保存された条件の後半は別に表示する。
6. 環境区間は推定結果の順位を見る前にbag画像・生点群から決め、別の区間表を版管理する。屋内室内、廊下、階段、屋外、静止等に加え、反復模様・反射・照度・ブレ・動体・面配置を記録する。未確認の境界時刻を凍結値として捏造しない。

速度判定はpose timestamp間の距離／時間で再計算する。単発10 m/s超、連続2区間5 m/s超の判定について、最初の超過区間と検知時刻を両方保存する。
pose出力周期が異なる場合はネイティブ周期と共通周期の結果を区別し、過去報告の時刻を無条件に転記しない。
オンライン監督の停止理由は事後の共通判定で上書きしない。

## 内部診断と主張の範囲

| 観点 | 必要な比較・注意 |
|---|---|
| LiDAR | 更新数、採用対応数、残差の分布、面法線の方向、重み付き情報行列の弱い方向。点群の形状固有値比と推定器の観測可能性を区別する |
| 画像 | 候補・採用・棄却、残差、空間分布、視差・深度、更新量。画素／特徴／LiDAR対応数を混同しない |
| IMU | 生の運動・飽和、速度、gyro／accel bias、更新前後の変化。bias増加をただちに原因と断定しない |
| 共分散 | 状態順序・単位・接空間・座標系・周辺化・更新前後を確認。座標を変える場合は対応する共分散も変換する |
| 資源・再現性 | CPU、RSS、処理時間、入力件数／順序、実行経路、反復差。既存記録の欠測を明記する |

未取得の診断は欠測とする。旧版と時間窓で定義が異なる値を同じ尺度で順位付けしない。
真値なしで共分散の校正やNEESを評価しない。小さい共分散は真の誤差が小さいことの証明にならない。
保存点群から再構成した法線情報は、当時の採用対応から得た情報と区別する。

主比較が測るのは各構成で画像を有効にしたシステム全体の変化である。
画像ONに伴うLiDAR更新時刻・点群分割の変化も記録する。
画像因子そのものの因果効果を調べる追加実験では、それらを固定して因子だけをON/OFFにし、別の実験IDを発行する。
環境・bias・共分散・残差の時間的関連と、因果が分離された結論を区別する。
この2bagの場面に限定した結論を基本とし、地形カテゴリ一般への優劣は追加データなしで断定しない。

## 保存と変更管理

元2秒プリセットのSHA256は `1607291b9223d16affa260dcf53e321956a7e689a9f1a383178ef72bf7ba6afe`。
現行dirty推定器のsrc/include/configとビルド定義は `current_estimator_source.tar.gz` に保存した。
このsnapshotから保存済みバイナリを再現できるかは未検証であり、ソースとバイナリの対応を証明したとは扱わない。
旧バイナリは既存隔離workspaceを参照する。
bag本体は合計約32.6 GBで、今回の監査では内容ハッシュ未取得。metadataハッシュ・サイズ・mtimeは内容同一性の証明ではない。比較入力の同一性確認は未完了項目として残す。

構成・較正・推定パラメータを変える場合はv2または補助実験とし、v1を上書きしない。
実行制御の派生設定と全差分、実行時の実効設定を必ず保存する。
過去の引き継ぎと報告は履歴として保持し、今回の主比較の仕様はこの文書とmanifestを参照する。

## 次の作業と実行条件

順序は、入力同一性／時刻／診断列の監査 → 生データによる環境区間表 → 保存済み8条件の同期集計・可視化 → 欠測診断の特定 → 必要最小限の追加取得。
最初の可視化はbagごとの軌道、位置／姿勢差、速度、bias、共分散、観測診断、場面画像を同じ時間軸で示す。
出発帰着評価を呼ぶ既存compare.pyをそのまま今回の評価器として実行しない。

新規再生は [AGENTS.md](../../../AGENTS.md) に従う。既存比較可能captureを優先し、短い監督付きprefixから開始する。
正のrate <=1、最大2 CPU、6 GiB hard cap／5 GiB停止、壁時間上限、2秒以内の資源・姿勢監視、全プロセス群の停止確認を必要とする。
発散済み条件をそのまま長時間へ延長せず、保存prefixを解析する。
本仕様作成時には新規再生・推定器の改変・精度調整を実施していない。
