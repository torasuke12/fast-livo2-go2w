# raw_20260907_114335 の加速度飽和

生の `/livox/imu` を読み出すと、各軸の加速度に約±4 gの繰り返しの上限・下限がある。
Xは−3.995633 / +4.004001 g、Yは−4.004290 / +3.995344 g、Z上限は+4.001204 g。
単なる大きな加速度という判定ではなく、同じ値で波形が頭打ちになっている。

| 区間（IMU先頭から秒） | サンプル数 | いずれかの軸が3.95 g以上 |
|---|---:|---:|
| 0–3 | 600 | 0 |
| 30–60 | 6000 | 5 |
| 75–100（上りを含む） | 5000 | 73 |
| 475–490 | 3000 | 0 |
| 532–536（下降） | 800 | 70 |
| 537–540（踊り場付近） | 600 | 0 |
| 541–545（下降） | 800 | 61 |
| 620–648 | 5600 | 0 |

元データ抽出・数値は `diagnostic_captures/online-20260930/imu_segments.py`、
`imu-raw.npy`、`acceleration-saturation.json` に保存。
区間は原因分析用であり、推定器に時刻を指定して切り替える処理はない。

Livoxの[公式MID-360通信プロトコル](https://github.com/Livox-SDK/livox_wiki_en/blob/master/source/tutorials/new_product/mid360/livox_eth_protocol_mid360.md)
でも、加速度の単位はg、IMU設定の加速度レンジには±4 gが記載されている。
このbagの取得時の設定照会記録はないため、設定コマンドの実行履歴まで確認できたわけではない。

飽和後の値を通常精度で積分すると、失われた衝撃の面積が速度誤差になる。
正負・各軸のクリッピングは対称に起きるとは限らず、時間平均を取っても相殺しない。
`typed-planes` は下降中に継続的な上向きのLiDAR補正を必要とし、通常距離では高さ誤差が残った。
対応上限6 cmの比較では補正が追いつかず、高さが発散した。
飽和が全誤差の単一原因であるとは断定せず、飽和対応の有無を全区間で比較する。

追加した設定は `lio.temporal.accel_saturation`（m/s²、0で無効）と
`accel_saturation_variance`（(m/s²)²）。検証候補は3.9×9.81と2500。
飽和した軸だけ、IMU事前積分の共分散に大きい不確かさを伝播し、LiDARによる速度修正を許す。
端点補間・台形平均でピークが消えても判定を失わない。gyroや非飽和軸の測定分散は直接変えない。
失われた加速度の値を復元する処理ではなく、飽和測定に対する保守的なガウス近似である。
短いスキャン内のdeskewにも未観測加速度の影響は残り得る。採否は完走後の未補正地図で判断する。


飽和処理の試験は13件すべて成功（`ctest-saturation.txt`）。
正負の衝撃の真の積分速度は相殺するが、正側のみ4 gでクリップされる合成走行では、
位置RMSが通常処理0.02696 mに対し飽和対応0.00317 mとなった。
これは既知真値の合成試験であり、実bagの達成精度とは区別する。

## 飽和時の分散を過大にした場合の問題（9月30日追記）

品質判定修正版 `plane-confidence-bias` でも、512秒付近に速度低下が生じた。
512–513秒の生IMUはXとZに各1サンプルのクリッピングがある。
512.099秒の更新で2積分区間が飽和判定され、X速度の事後分散が直前の約0.00075から
0.112 (m/s)²へ増えた。その後のスキャン更新はX速度を一度に約+0.28 m/s修正し、
510秒の−1.47 m/sから515秒には−0.56 m/sとなった。518秒には約−1.44 m/sへ回復したが、
その間の移動距離は過小推定される。面の品質判定だけではこの失敗を防げなかった。

分散2500は未観測加速度の標準偏差50 m/s²に相当する比較用の仮定であり、
このbagで較正した値ではない。飽和を無視する場合の過信と、IMU拘束を弱めすぎて
廊下の曖昧な面対応へ速度が引かれる場合の両方を評価する必要がある。
同じコードで分散を全区間一律100・400へ変更した全区間比較を行った。
時刻や走行場所によって分散を切り替える処理はない。100も真の飽和誤差分散と確定した値ではない。

分散100・標準biasでは512.1秒のX速度分散は約0.0058 (m/s)²となり、
513–516秒のX速度は約−1.40～−1.44 m/sを維持した。帰着の壁の差は11.6–15.0 cm、天井10.5 cm。
分散100のbias追従改善版ではX壁が約44 cm、分散400の標準版は約54–60 cmずれた。
分散100・標準biasの反復も512秒の速度低下を抑えたが、帰着のX壁に約0.88 mのずれが残った。
飽和分散の修正だけで全区間精度の再現性が得られたとは判断しない。時間窓の延長とLIVOを追加比較する。
平均軌道の書き換えや、帰着位置への拘束は行っていない。
